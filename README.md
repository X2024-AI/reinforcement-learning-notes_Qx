# Reinforcement-Learning-Notes
This repository archives personal reinforcement learning learning materials, including hand-derived mathematical formulas, recorded learning puzzles, complete algorithm implementations and compiled notebook PDFs. All docs are formatted with Markdown or LaTeX.

## Repository Structure
- /algorithms: RL source codes implementation
- /latex: LaTeX source files for formulas & documents
- /pdf: Exported notebook PDF files

## Environment Setup
Run the following commands to create and activate the Conda environment:
```bash
conda env create -f environment.yml
conda activate your_env_name
```
